# Metriczone

Metriczone website: **Measure. Understand. Improve.**

A static company concept by Miroslaw Staron, connecting measurement programs, information quality, informed decisions, and agentic AI.

## Files

- `index.html`: new company homepage, including responsive navigation and interactive measurement examples.
- `metriczone.png`: approved logo.
- `research.html`: preserved metrics journal, formerly the homepage.
- `posts.json` and `.github/workflows/blog.yml`: existing journal content and scheduled blog sync, retained.

## Preview and publishing

Serve the repository root with any static web host. No build step is required. Keep `metriczone.png` beside `index.html`.

To use metriczone.com, configure the domain and HTTPS in your host and apply the DNS records that host supplies. The homepage already uses https://metriczone.com/ as its canonical URL. This commit does not change domain or hosting settings.

The contact button links to Miroslaw's University of Gothenburg profile. Replace it with a business contact destination when ready. The book tile is a typographic representation, not the publisher's cover. No analytics or contact submission backend is included.
